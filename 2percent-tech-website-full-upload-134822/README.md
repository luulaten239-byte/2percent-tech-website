# 2%Tech Website Demo

Static website demo for the 2%Tech event/community site redesign.

## Preview

Open `index.html` directly in a browser.

## Deploy

This is a static site. It can be deployed with GitHub Pages, Vercel, Netlify, or any static file host.

For GitHub Pages:

1. Push this folder to a GitHub repository.
2. Open the repository settings.
3. Enable Pages from the `main` branch and root folder.

## Files

- `index.html` - main page
- `assets/` - images, logo, and videos used by the page
